# Data Science Implementation Agent

## Overview

The Data Science Implementation Agent is an AI-powered tool designed to assist students with implementing data science projects.

The agent takes a student's existing work and project requirements as input and helps them continue, improve, and implement their data science workflow.

## Student Inputs

The student provides:

- Existing code
- Outcome/response variable
- Predictor variables
- Desired programming language
- Work already completed
- Additional project requirements or constraints

## Intended Workflow

The agent will:

1. Understand the student's existing work and project requirements.
2. Inspect and interpret the existing code.
3. Identify gaps or issues in the current implementation.
4. Recommend appropriate data science approaches.
5. Generate or modify code where appropriate.
6. Explain the changes and methodology to the student.
7. Help the student progress toward a working analysis/model.

## Project Goals

The project aims to make data science implementation more accessible to students while encouraging understanding of the underlying methodology rather than simply producing code.
